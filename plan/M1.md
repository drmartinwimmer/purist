# Milestone 1: Core CLI Architecture & Cargo.toml Lint Configurator Tool

**Milestone Goal:** Initialize the Rust CLI crate structure with `clap`, establish unified diagnostic data structures and reporting formats, and implement the `code-review configure-lints` tool using `toml_edit` to safely and idempotently inject strict Clippy lint configurations into `Cargo.toml` without stripping comments or altering unrelated tables.

  - Add `toml_edit` and `thiserror` dependencies to `Cargo.toml`.
  - Create `src/tools/cargo_toml.rs` and implement:
    - `LintProfile` enum (`Strict`, `Standard`).
    - `ConfigureResult` struct (`modified: bool`, `lints_configured: usize`).
    - `CargoTomlError` enum deriving `thiserror::Error`.
    - `configure_lints(manifest_path: &Path, profile: LintProfile) -> Result<ConfigureResult, CargoTomlError>`.
    - `remove_lints(manifest_path: &Path) -> Result<ConfigureResult, CargoTomlError>`.
  - Ensure Invariants:
    - Comment and whitespace preservation using `toml_edit`.
    - Three manifest cases: virtual workspace (`[workspace]` without `[package]`: only `[workspace.lints.clippy]`, no `[lints]`), root package with workspace (`[workspace.lints.clippy]` and `[lints] workspace = true`), and single/member crate (`[lints.clippy]` directly).
    - Full idempotency (repeated execution returns `modified: false` and leaves content byte-identical).
    - Configures all required Clippy lint groups: Don't Panic, Don't Fail Silently, Memory Safety, Numerics, Avoidable Pitfalls, and Suppression Hygiene (Strict: 34 lints, Standard: 31 lints).
    - Clean removal and parent table pruning: `remove_lints` prunes empty `[lints]` or `[workspace.lints]` tables.
    - Structural error detection: Returns `CargoTomlError::InvalidStructure` on non-table scalars.
  - Connect subcommand in `src/main.rs`.
  - Write unit tests in `src/tools/cargo_toml.rs` verifying comment preservation, idempotency, virtual vs root workspace vs crate targeting, profile variations, pruning, and error cases.
  - Verify with `cargo test`.
  - Describe Jujutsu change: `jj --no-pager describe -m "plan-M1-T2: feat: implement Cargo.toml lint configurator using toml_edit"`.
